# Sistema Financeiro

Aplicacao Next.js para gestao financeira com foco em fluxo de caixa, previsao de recebimento liquido e reconciliacao de dados.

## Comandos

```bash
npm run dev
npm run lint
npm run typecheck
npm run check:boundaries
npm run check:contracts
npm run test
npm run build
npm run check
```

## Endpoints base

- GET /api/health
- GET /api/financial/dashboard
- GET /api/financial/transactions
- GET /api/financial/imports
- GET /api/financial/reconciliation
